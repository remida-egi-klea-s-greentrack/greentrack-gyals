# GreenTrack Frontend

Dashboard interaktiv për monitorimin e konsumit të energjisë.

## Quick Start

```bash
npm install
npm run dev
```

**Shënim:** Backend duhet të ekzekutohet në port 8080.

## Features

- Kartela përmbledhëse (konsumi, ora e pikut, anomalitë)
- Grafikë interaktivë (Recharts)
- Chat assistant
- Responsive design

## Teknologjitë

- React 19.3
- Recharts 3.10
- Vite 8.3

## API

Frontend lidhet me 4 endpoints:
- `GET /consumption`
- `GET /anomalies`
- `GET /forecast`
- `POST /chat`
